Веб-приложение для проведения психологического тестирования 
по методике **Кеттелла 16PF**.

Проект разработан на языке **Python** с использованием фреймворка **Flask** 
и предназначен для автоматизации процесса тестирования, 
хранения результатов, просмотра отчётов.

---
## Функционал

* Авторизация.
* Регистрация.
* Управление пользователями.
* Проведение тестирования по методике Кеттелла.
* Формирование PDF-отчётов.
* Поиск участников.
* Фильтрация результатов.
---

# Структура проекта

```text
models/             Модели базы данных
routes/             Маршруты приложения
templates/          HTML шаблоны
static/             CSS, JavaScript, изображения
utils/              Логика расчета теста
migrations/         Миграция
forms.py            Flask-формы
config.py           Конфигурация
extensions.py       Инициализация
__init__.py         Создание и настройка
run.py              Точка запуска 
requirements.txt    Зависимости проекта
```

---

## models/

ORM-модели SQLAlchemy.
```text
- quiz.py
  - participants - пользователи сформированные с теста.
  - questions - список вопросов > options - список ответов.
  - answer - ответы пользователей при прохождении теста.
  - testResult - результаты теста (сырые балла, стены, вывод)
- user.py
  - User - пользователи личного кабиета.
```
---

## routes/

### user.py

* регистрация пользователей;
* авторизация;
* изменение профиля;
* управление пользователями;
* просмотр результатов;
* поиск;
* фильтрация отчета;
* удаление пользователей.

---

### quiz.py

* регистрация участника тестирования;
* отображение вопросов;
* сохранение ответов;
* навигация между страницами теста;
* завершение тестирования;
* вычисление итогового результата.

---

### pdf.py

* генерация PDF-отчётов;
* скачивание документов.

---

## utils/

Содержит логику формирование результата.

**cattell.py**

Хранятся ключи методики Кеттелла, расчёта шкал.

---

## forms.py

Пользовательские формы.
* авторизация;
* регистрация пользователя;
* изменения профиля;
* поиск;
* прохождения тестирования.
